# 코인 오류 진단과 데이터 보관 산정

## 오류 기록 (2026-09-13 구현)

공개 API 실패는 journald의 `UPBIT_PUBLIC_API_ERROR`에 UTC 시각, endpoint, symbol, HTTP status, 오류 코드, Remaining-Req, Retry-After, 시도 횟수, 경과 시간, 재시도 여부를 남긴다. 평가 보고서와 감사 이벤트의 error_details, 감시 보고서의 details에도 전달한다. 예외 발생 위치는 파일명·함수·줄 번호로 기록한다. 인증 헤더, 응답 원문, 임의 예외 메시지는 기록하지 않는다. 429/418 재시도 정책과 매매 배점은 변경하지 않는다.

```bash
sudo journalctl -u ml-crypto --since today --no-pager -g UPBIT_PUBLIC_API_ERROR
```

과거 RuntimeError의 원인을 새 로그로 소급 확정할 수 없다. 감시 latest 파일은 덮어쓰므로 API 실패 이력은 journal 보관 설정도 함께 확인한다.

## 현재 코드가 요구하는 시간 구간

| 자료 | 수집·평가 주기 | 계산에 필요한 구간 | 보관 제안 |
|---|---|---|---|
| 15분봉 | 평가 15분마다 API 100개 요청 | 확정 연속 25봉 = 6시간 15분. MA20은 5시간, 거래량 비교는 21봉 = 5시간 15분. 최근 확정봉 종료 후 15분 미만이어야 함 | 운영 캐시 2일 이상, 평가에 사용한 원본 스냅샷은 90일 |
| 전체 KRW 거래대금·경고 상태 | 15분 | 최신 24시간 누적 거래대금 값, ticker 60초 이내. 전일별 유동성 참고 통계는 최근 7일 중 완료일 최소 3일 | 원본 관측 8일 이상, 일별 집계 90일 이상 |
| 이전 선정 목록 | 15분 갱신 | 최근 1시간 | 현재 목록과 변경 이력 보관 |
| 호가 | 목표 15초 | 평가·체결 시 30초 이내. 신호 유효기간 20분, 결과 라벨 60~75분 | 전체 원본 호가 7일, 진입·청산·라벨 산출 근거와 판단 스냅샷 90일 이상 |
| 신호·장부·결과 라벨·전략 버전 | 평가·체결 때 | 보유 한도 1시간은 정상 관측 시 목표이며 장애로 초과 가능. 미해결 신호·보유 포지션은 날짜로 삭제 금지 | 1년 이상 또는 소형 영구 보관, 비교 연구용 원본은 별도 압축 보관 |

현재 100봉 요청은 봉이 빠짐없이 존재할 경우 약 25시간 범위다. 무거래 봉 누락이 있으면 더 긴 시간 범위가 될 수 있고, 데이터를 오래 보관한다고 연속 25봉 검사가 자동 통과하지는 않는다. 유동성 7일 통계는 참고 정보이며 현재 점수의 직접 입력은 아니다. 호가 books 과거 행은 다음 평가 계산의 입력 캐시가 아니며 장부 검증 자료다. 75분은 라벨 관측 구간이지 전체 자료 삭제 기준이 아니다.

## 저장량 계산

감시 20종목 × 하루 86,400초 / 15초 = 약 115,200호가/일. 종목 수·API 지연·추가 평가 관측에 따라 실제 건수는 달라진다.

서버 이전 백업 research.db 290,971,648 bytes → 약 31시간 57분 후 945,287,168 bytes. 증가량 654,315,520 bytes / 약 1.331일 = 약 0.492 GB/일(십진 단위).

- 동일 증가 추세의 7일: 약 3.44 GB
- 30일: 약 14.8 GB
- 90일: 약 44.3 GB

이는 연구 DB 전체의 단기 관측 증가율이며 호가만의 용량이나 미래 보장값이 아니다. audit DB, JSON 보고서, journal, 백업과 다른 서비스 공간은 별도다. 현재 여유 약 22.4 GB만으로 90일 원본을 로컬에 계속 쌓는 운영은 불가능하다. 운영 전체 호가 7일과 장기 근거 자료 분리·압축·외부 보관을 제안한다.

## 적용 상태

위 보관 기간은 설계 제안이며 자동 삭제는 적용하지 않았다. 삭제 구현 전 원본 참조 관계를 확인하고 미해결 포지션·신호를 보호해야 한다. SQLite DELETE는 즉시 파일 크기를 줄이지 않으므로 압축 보관과 공간 회수 절차를 별도 설계한다. 장기 보관만으로 전략 정확도·수익성이 입증되지 않으며 시장 국면별 외부 표본 검증이 필요하다.
