# 점수별 투자금과 사용자 실거래 준비

## 확정 기준 (2026-09-15)

고정 배분 기준 자금은 1,000,000원이다. 수익 발생에 따른 자동 복리 증액은 하지 않는다. 손실로 현금이 줄면 가용자금 검사를 우선한다.

| 전략 점수 | 배분 | 매수 원금 |
|---|---|---|
| 0.65 미만 | 0% | 진입 안 함 |
| 0.65 이상 0.75 미만 | 10% | 100,000원 |
| 0.75 이상 0.85 미만 | 15% | 150,000원 |
| 0.85 이상 1 이하 | 20% | 200,000원 |

각 전략의 진입 기준을 먼저 통과해야 한다. 실험 전략은 기존 0.70 진입 기준을 유지하며, 금액 계산에는 자신의 점수를 사용한다. 같은 점수면 같은 배분표를 적용하는 것이며 서로 다른 점수를 같은 예측력이라고 가정하지 않는다.

최대 동시 보유 3종목, 시장·유동성·개별 청산 조건을 유지한다. 원금 외 매수 수수료와 미체결 예약금도 자금 검사에 포함한다. 일일 손실액에 따른 자동 중단·다음 날 자동 재개 규칙은 없다. 시스템 오류·주문 불명·잔고 불일치 차단은 일일 손실 한도와 별개다.

새 모의 배분 장부는 `data/comparison_v2.db`, 보고서는 `reports/comparison_latest.json`이다. 기존 `comparison.db`는 신규 진입을 중단하고 잔여 포지션을 기존 조건으로 관리한다. 기존 연구용 `research.db`의 고정 10만원 모형은 과거 기준 비교용으로 유지하며 새 배분 성과와 합산하지 않는다.

실거래 구성요소의 `submit_scored_buy`도 동일 배분 함수와 실제 수수료 포함 100만원 자금 검사를 사용한다. 가용현금·기존 투자 및 예약금은 향후 계정 대조 실행기가 전달해야 한다. 현재 실거래 데몬 연결은 미완료이므로 이 함수만으로 실거래 준비 완료가 아니다.

## 사용자가 준비할 내용

1. 업비트 거래 계정에 운영자금 약 100만원을 확보한다. 기존 보유 코인·미체결 주문이 있으면 자동매매 자금과 분리 여부를 알려준다. 초기 운영은 타 수동 주문과 섞이지 않는 자금 구성이 권장된다.
2. 업비트 PC 웹 Open API 관리에서 키를 발급한다. 필요한 권한은 자산조회·주문조회·주문하기다. 입출금 권한은 필요 없다.
3. 허용 IP에는 `smart-beauty.kr`이라는 도메인 대신 **서버가 외부 API에 접속할 때 사용하는 고정 공인 IPv4**를 등록한다. DNS 주소와 실제 송신 IP가 같은지 서버 네트워크 설정에서 확인한다.
4. 키를 아래 서버 전용 파일에 직접 입력한다. GitHub·채팅·명령행 인자·로그에 키를 넣지 않는다.

```bash
sudo install -d -m 700 /etc/ml-crypto
sudo test -e /etc/ml-crypto/upbit-credentials || sudo install -m 600 /dev/null /etc/ml-crypto/upbit-credentials
sudoedit /etc/ml-crypto/upbit-credentials
```

파일 형식(자리표시자를 발급받은 값으로 교체):

```text
UPBIT_ACCESS_KEY=발급받은_Access_Key
UPBIT_SECRET_KEY=발급받은_Secret_Key
```

이 파일은 현재 모의 서비스에서 읽지 않는다. 키 입력 자체로 실거래가 시작되지 않는다. 입력 후에는 **키 준비 완료 여부와 기존 보유·미체결 유무만** 알려준다.

## 실거래 전 개발·검증 잔여 항목

- 실제 계정 수수료·최소 주문·잔고 조회와 공통 비교 조건 반영.
- 실제 포지션·부분 체결·미체결 예약금 대조, 불일치 시 신규 진입 차단.
- 자동 실거래 모멘텀 실행기, 긴급 중단·청산, 실체결/모의체결 비교 보고 연결.
- 별도의 소액 주문 검증 범위 확정 후 활성화. 현재 실거래는 비활성 상태다.

공식 근거: [API 키 발급과 허용 IP](https://docs.upbit.com/kr/kr/docs/api-key), [기능별 권한](https://docs.upbit.com/kr/reference/auth).
