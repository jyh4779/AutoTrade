# 프로젝트 지침 목차

이 폴더는 Claude와 Codex가 공유하는 프로젝트 설계·작업 지침의 원문이다. `docs/`는 날짜별 분석, 검증 증거, 과거 계획을 보관한다. 과거 보고서를 현재 운영 규칙으로 취급하지 않는다.

## 문서 관리

- 현재 구현, 목표 설계, 미완료 항목을 명시적으로 구분한다.
- 코드 동작을 바꾸면 해당 파트의 지침도 갱신한다. 현재 코드와 문서가 다르면 차이를 확인하고 실제 동작을 보고한다.
- 운영 수치의 원본은 실행 코드·설정이다. 문서의 예시 수치를 새 기본값으로 적용하지 않는다.
- 정책은 담당 파트 한 곳에 작성하고 다른 문서는 링크로 참조한다.
- 새 파트 추가 시 이 목차에 등록한다. 에이전트별 정책 사본이나 별도의 코인용 AGENTS.md를 만들지 않는다.

기준일: 2026-09-11. 운영 구현의 새 경로 이전과 기존 경로 호환 처리를 적용했다. DB 이전과 코인 실행은 포함하지 않으며, 정확한 완료 범위는 [전환 현황](07-migration.md)에 기록한다.
