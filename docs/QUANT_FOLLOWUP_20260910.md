# 2026-09-10 후속 수정

## 적용한 변경

- 코스피 대표 ETF만 주문 허용 판단에 사용한다. -1% 미만은 차단, -0.5% 미만은 약세로 분류한다. 종목 배점 및 기존 동적 기준값 로직은 유지한다.
- 시장 데이터의 기준일이 당일인지 확인한다. 공급자의 장중 시각은 검증하지 못하므로 수신 시점 일봉이라는 사실을 기록한다. 조회 실패·오래된 데이터는 주문 차단이다.
- 시장 필터가 차단해도 종목 평가와 가상 배분을 진행한다. 주문 루프 앞에서 허용 여부를 확인하고 차단 사유 및 가상 배분 수를 기록한다.
- 코스피 순위 목록이 100개 미만이면 거래대금 대체 조회를 시도한다. 더 큰 목록이 확보된 경우 대체하며, 확보하지 못하면 REDUCED 상태와 실제 수량을 기록한다.
- 캐시에 시장, 생성일, 종목 목록, 내용 해시를 함께 저장하고 로드 시 검증한다. 기존 캐시 검증 실패 시 해당 캐시로 평가하지 않는다.
- 감사 보고서는 복구된 작업의 최초 실패를 WARN으로 보존한다. 전일 시작된 프로세스도 버전 확인 대상으로 포함하며, 시작 기록을 현재 생존 증거로 간주하지 않는다.

## 검증

- 회귀 테스트 35개 통과. 코스피 단독 시장 판단, 오래된 시장 데이터 차단, 시장 차단 중 평가 지속, 주문 루프 미진입 검증 포함.
- Python 컴파일 및 diff 공백 검사 통과.
- 주문 없는 실제 데이터 사전 분석 실행 성공. 28종목 확보. 장 마감 후 실행한 것으로 오전 판단과는 별개다.
- 주문 없는 전체 평가도 종료 코드 0. 저장 입력의 기술 점수 재현 14건 PASS.
- 최초 검증에서 가격 범위 오류 종목의 종료 사유 누락 2건을 감사가 검출했다. 예외 경로에 UNKNOWN 종료 기록을 추가한 후 재검사에서 28종목 모두 종료 사유가 기록됐다. 최초 검증의 FAIL 이력은 삭제하지 않는다.

## 적용 방식

다음 사전 분석·매수 판단·감사 작업은 새 프로세스에서 수정 코드를 읽는다. 이미 실행 중인 상주 프로세스의 시작 버전은 바뀌지 않으며 버전 경고를 임의로 제거하지 않는다. 기존 캐시에는 새 메타데이터가 없을 수 있으므로 다음 사전 분석의 정상 완료를 확인해야 한다.

## 미완료 범위

이 변경으로 전체 수정 계획이 완료된 것은 아니다. 종목 유형 마스터에 기반한 필터 교체, 100종목 확보가 가능한 조회 경로, 중복 프로세스·실제 생존 검사, 시점별 분봉 수집과 미매수 가상 손익, 외부 표본 배점 검증은 추가 구현 및 데이터 확보가 필요하다. 현재 종목코드 끝자리 필터는 유지된다. 시장 위험 필터의 ETF 일봉에는 정확한 공급자 장중 시각이 없어 WARN으로 남긴다.

체결과 청산의 실운영 검증 및 수익성 검증도 아직 완료되지 않았다.
